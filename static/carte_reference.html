📚 Listes

Créer une liste :
n = [] # Liste vide n = [1, 2, 3] # Liste de nombres n = ["a", "b", "c"] # Liste de chaînes (homogène!)
Opérations courantes :
Opération Exemple Effet
Accès n[0] Accède à l'élément d'index 0
Longueur len(n) Nombre d'éléments
Ajouter n.append(4) Ajoute à la fin (in-place)
Enlever n.pop() Retire et retourne le dernier
Inclus ? 1 in n Booléen : élément dans la liste ?
Itération :
# Par élément for x in [1, 2, 3]: print(x) # Par indice for i in range(len(n)): print(n[i])

🎯 Fonctions

Signature et spécification :
def multiplier(x: int, y: int) -> int: """Retourne le produit de deux entiers. Préconditions: x et y doivent être des entiers. """ return x * y
Appel :
result = multiplier(3, 4) # result = 12
Return multiple :
def divmod_custom(a: int, b: int) -> tuple: quotient = a // b remainder = a % b return quotient, remainder # Retourne un n-uplet q, r = divmod_custom(17, 5) # q = 3, r = 2

🎲 Compréhensions de Listes

# Transformation : List[int] → List[int] doubles = [x * 2 for x in [1, 2, 3]] # [2, 4, 6] # Filtrage : List[int] → List[int] pairs = [x for x in [1, 2, 3, 4, 5] if x % 2 == 0] # [2, 4] # Transformation + filtrage result = [x * 2 for x in [1, 2, 3, 4, 5] if x > 2] # [6, 8, 10]

⚠️ Pièges Courants

Division entière vs flottante :
7 / 2 # 3.5 (division flottante) 7 // 2 # 3 (division entière)
Indexation : commence à 0 !
l = ['a', 'b', 'c'] l[0] # 'a' (premier élément) l[-1] # 'c' (dernier élément)
Copie vs Référence :
a = [1, 2, 3] b = a # b est une RÉFÉRENCE à a b.append(4) # modifie aussi a! # Pour copier vraiment : c = a.copy() # ou a[:] d = list(a)
Range s'arrête avant la fin :
range(5) # 0, 1, 2, 3, 4 (pas 5!) range(1, 5) # 1, 2, 3, 4 (pas 5!)
Les listes doivent être homogènes :
# BON nombres = [1, 2, 3] # List[int] noms = ["Alice", "Bob"] # List[str] # MAUVAIS (mélanges les types) mixte = [1, "deux", 3.0] # ❌ À éviter!

✅ Structure Recommandée d'un Programme

def ma_fonction(x: int, y: int) -> int: """ Calcule quelque chose. Préconditions: x et y > 0 """ return x + y # Jeu de tests assert ma_fonction(2, 3) == 5 assert ma_fonction(0, 0) == 0 # Programme principal print(ma_fonction(10, 20))
